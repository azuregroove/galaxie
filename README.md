# Mapa Mléčné dráhy („Galaxie“)

Interaktivní 3D mapa naší Galaxie: exoplanety, hvězdokupy, mlhoviny, černé díry, pulsary, hvězdy z Gaia DR3 a další.

**Web: https://azuregroove.github.io/galaxie/**

Tohle repozitář obsahuje jen sestavený web (výstup buildu), který servírují GitHub Pages.
Přepisuje se automaticky při každém nasazení, historii neuchovává. Vývoj probíhá jinde.

Dlaždice hvězd Gaia do 500 pc leží v samostatném repu
[azuregroove/galaxie-data](https://github.com/azuregroove/galaxie-data).
